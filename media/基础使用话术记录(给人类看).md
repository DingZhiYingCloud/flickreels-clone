## 6. 前端整站 SEO 优化（title / h1 / alt）

```
请你优化一下前端整站（全部页面），不要出现以下问题：
- title 标题太短
- 缺少图像的 Alt 属性

等

```

## 9. 导出"不依赖任何后端"的独立静态版目录

> 当某页面已完成克隆（或在 Django 中正常运行）后，如果你希望它同时存在一份**纯静态、可独立分发**的版本（比如单独投放、发给别人直接打开），可用下面的话术让 AI 直接生成。

```
请把我已生成的那个页面，单独再导出一份"不依赖任何后端"的纯静态版本：

1. 在项目根目录新建一个独立目录，命名形如 <页面名>-standalone；
2. 把页面所需的全部资源放进该目录：index.html、favicon.ico、css/、js/（页面 JS + 本地 jQuery）、images/（全部图片），HTML 内所有资源引用一律改为目录内相对路径；
3. 版本号 / 更新日志 / 详情链接等原本由后端注入的文案，直接固化为当前静态内容；
4. 不含任何后端功能：不要小影 API 友情链接、不要 Django 模板标签/中间件处理、不要任何接口请求；
5. 视觉与交互与原页面保持一致（背景大图、轮播、关闭吸底条、自适应等）；
6. 完成后用浏览器以 file:// 方式直接打开验证：CSS/JS/图片均从本目录加载、无控制台报错；
7. 输出该目录的结构说明与使用方法。
```
